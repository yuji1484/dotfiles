# tmux チートシート

## 基本情報

- **Prefix キー**: `C-s` (Ctrl + s) — すべての操作はこれを先に押す

---

## セッション操作

| 操作 | コマンド |
|------|----------|
| 新規セッション | `tmux new -s <name>` |
| セッション一覧 | `tmux ls` |
| アタッチ | `tmux a -t <name>` |
| デタッチ | `C-s d` |

---

## ウィンドウ操作（タブのようなもの）

| 操作 | キー |
|------|------|
| 新規ウィンドウ | `C-s c` |
| 次のウィンドウ | `C-s n` |
| 前のウィンドウ | `C-s p` |
| ウィンドウ選択 | `C-s <番号>` |
| ウィンドウ名変更 | `C-s ,` |

---

## ペイン操作（画面分割）

| 操作 | キー |
|------|------|
| **縦分割** | `C-s v` |
| **横分割** | `C-s s` |
| ペイン移動 | `C-s h/j/k/l` (vim風) |
| ペインサイズ変更 | `C-s H/J/K/L` (繰り返し可) |
| ペイン削除 | `C-s q` |

---

## コピーモード（スクロール・テキスト選択）

| 操作 | キー |
|------|------|
| コピーモード開始 | `C-s [` |
| 移動 | `h/j/k/l` または矢印キー |
| 選択開始 | `v` |
| 矩形選択 | `C-v` |
| コピー＆終了 | `y` または `Enter` |
| コピーモード終了 | `q` |

※コピーした内容は `pbcopy` 経由でmacOSのクリップボードに入る

---

## その他

| 操作 | キー |
|------|------|
| **設定リロード** | `C-s r` |
| コマンドモード | `C-s :` |

---

## 設定の特徴

- **マウス有効** — スクロールやペイン選択がマウスでできる
- **履歴10万行** — 大量のログも遡れる
- **インデックス1始まり** — ウィンドウ・ペイン番号が1から
- **ステータスバー上部** — 時刻・バッテリー等を表示
- **カラーテーマ** — iceberg_minimal を使用
